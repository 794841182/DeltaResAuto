自动检测分辨率 v1.2.0
桌面分辨率自动切换工具 · 冷渡-Van1sh

一、它是做什么的
  监测指定游戏进程。游戏启动后，把桌面分辨率（和刷新率）切成你设定的“游戏模式”；
  游戏退出后，自动恢复成原来的桌面分辨率。全程在后台，托盘常驻。

二、第一次使用
  1. 打开程序，在“游戏运行时”里选游戏分辨率，“刷新率”可选“跟随系统”或具体 Hz。
  2. “退出游戏后”填桌面分辨率（一般保持默认即可，程序也会记住切换前的真实模式）。
  3. 目标进程默认已填好三角洲行动，也可以在“监测游戏”里换。
  4. 点“应用设置”。之后启动游戏即可，程序会自动切换。

三、刷新率
  下拉里列出的 Hz 是显卡在该分辨率下真正支持的模式，来自系统枚举，不是硬编码。
  选“跟随系统”＝沿用当前桌面刷新率。选了具体 Hz 后，判断“是否已切换”会同时比较分辨率与刷新率。

四、配置与备份（重点）
  配置目录：%LOCALAPPDATA%\DeltaResAuto
    settings.ini          当前配置
    settings.ini.bak      上一次的配置
    backup\               历史备份（settings-时间.ini，最多保留 10 份；安装升级时另有 install-时间.ini）
    auto.log              运行日志
    crash.log             崩溃日志（发生过崩溃才生成）
  读取配置时，如果 settings.ini 丢失或损坏，会自动回退到 .bak，再回退到 backup 里最新的一份。
  写入配置时，只有内容真的变了才会先备份旧文件，避免刷屏式备份。

五、卸载
  在 Windows“设置 → 应用”里找到“自动检测分辨率”卸载，或运行安装目录下的 uninstall.exe。
  卸载默认保留配置与备份；需要彻底清理时勾选“同时删除配置与备份”。

六、文件完整性
  安装目录里有 manifest.sha256，记录了每个文件的 SHA256。
  安装程序在释放文件前校验安装包，释放完成后再复核一遍，任何不一致都会中止安装。
  手动校验可在 PowerShell 里执行（在安装目录）：
    Get-Content manifest.sha256 | ForEach-Object {
      $h,$f = $_ -split ' \*',2
      if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { "损坏: $f" }
    }

八、常见问题
  · 切不回去：点“立即恢复桌面分辨率”，或退出程序（正常退出会自动恢复）。
  · 检测不到游戏：确认进程名（任务管理器 → 详细信息），在“目标进程”里改成实际 exe 名。
  · 双开/重复启动：程序单实例，重复启动只会唤出已有窗口。
